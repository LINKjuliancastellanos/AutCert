WEB SCRAPING DE GOOGLE DRIVE - INICIO RÁPIDO
================================================================================

📋 INSTALACIÓN (PRIMERA VEZ)
================================================================================

1. Instalar dependencias de Python:

   pip install -r requirements.txt

   O manualmente:
   pip install selenium webdriver-manager pywin32


2. Iniciar sesión en Drive (SOLO 1 VEZ):

   Ejecutar: 1_Iniciar_Sesion.bat

   ✓ NO necesitas cerrar tu Chrome actual
   ✓ Abre un Chrome completamente separado (como modo invitado)
   ✓ NO interfiere con tus sesiones activas del navegador
   ✓ Perfil 100% aislado solo para Drive
   ✓ 120 segundos (2 minutos) para iniciar sesión cómodamente

   Pasos:
   - Se abrirá un Chrome independiente (sin tus sesiones actuales)
   - Iniciar sesión en Google manualmente
   - Navegar a drive.google.com
   - Ir a tu carpeta de evidencias
   - Esperar 2 minutos (el script cuenta automáticamente)
   - La sesión se guardará en un perfil aislado
   - Chrome se cierra cuando termine


================================================================================
💻 USO NORMAL (UNA HU)
================================================================================

Para completar una certificación de HU:

1. Ejecutar: 2_Completar_HU.bat

2. Ingresar el número de HU cuando se solicite
   Ejemplo: 273920

3. El script automáticamente:
   ✓ Buscará la carpeta "Evidencias HU273920" en Drive
   ✓ Extraerá los links de todas las carpetas CP
   ✓ Actualizará el Excel de certificación con los links


================================================================================
🚀 PROCESAMIENTO MASIVO (TODAS LAS HUs)
================================================================================

Para procesar TODAS las certificaciones de una vez:

1. OPCIONAL: Ejecutar: 4_Verificar_Estado.bat
   → Muestra cuántas certificaciones tienen links y cuántas faltan

2. Ejecutar: 3_Procesar_Masivo.bat

3. El script automáticamente:
   ✓ Escanea TODAS las certificaciones en AyN, RyC y Transversal
   ✓ Procesa cada una secuencialmente
   ✓ Muestra barra de progreso en tiempo real
   ✓ Genera reporte JSON al finalizar

4. OPCIONAL: Ejecutar: 4_Verificar_Estado.bat
   → Verifica cuántas quedaron completas después del proceso

================================================================================
🐛 PROBLEMAS COMUNES
================================================================================

"ERR_INVALID_ARGUMENT" o "SessionNotCreatedException":
→ El perfil aislado ahora evita estos errores automáticamente
→ NO necesitas cerrar Chrome
→ Si persiste:
  1. Ejecuta: LIMPIAR_PERFIL_CHROME.bat
  2. Ejecuta: 1_Iniciar_Sesion.bat

"No se encontró la carpeta de HU en Drive"
→ Verificar que existe "Evidencias HU{numero}" en Drive (formato exacto)
→ Verificar que la sesión esté guardada

"No se encontró certificación para HU"
→ Verificar que existe Certificacion_QA_{numero}.xlsx
→ Verificar que está en EntregaCerts/Certificaciones/AyN, RyC o Transversal

"Error al actualizar Excel"
→ Cerrar el archivo Excel si está abierto
→ Verificar permisos de escritura

================================================================================
🔒 MODO AISLADO
================================================================================

El sistema ahora usa un "perfil aislado" para Chrome:

• ¿Qué es? → Un Chrome completamente separado de tu Chrome personal
• ¿Por qué? → Evita conflictos y errores como ERR_INVALID_ARGUMENT
• ¿Ventajas? → NO necesitas cerrar tu Chrome actual para usar el script
• ¿Seguro? → Tu sesión personal de Chrome NO es accedida por el script

Tu Chrome personal y el Chrome del script pueden estar abiertos al mismo tiempo
sin ningún problema.
