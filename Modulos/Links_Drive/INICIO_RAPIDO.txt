================================================================================
WEB SCRAPING DE GOOGLE DRIVE - INICIO RAPIDO
================================================================================

INSTALACION (PRIMERA VEZ)
================================================================================

1. Instalar dependencias de Python:

   pip install -r requirements.txt

   O manualmente:
   pip install selenium webdriver-manager pywin32 playwright

2. Instalar navegador de Playwright (RECOMENDADO):

   playwright install chromium

3. Iniciar sesion en Drive (SOLO 1 VEZ):

   OPCION A - Playwright (RECOMENDADO):
   Ejecutar: 7_Iniciar_Sesion_Playwright.bat

   OPCION B - Selenium (alternativa):
   Ejecutar: 1_Iniciar_Sesion.bat

   - NO necesitas cerrar tu Chrome actual
   - Abre un Chrome completamente separado (como modo invitado)
   - NO interfiere con tus sesiones activas del navegador
   - Perfil 100% aislado solo para Drive
   - 120 segundos (2 minutos) para iniciar sesion comodamente

   Pasos:
   - Se abrira un Chrome independiente (sin tus sesiones actuales)
   - Iniciar sesion en Google manualmente
   - Navegar a drive.google.com
   - Ir a tu carpeta de evidencias
   - Esperar 2 minutos (el script cuenta automaticamente)
   - La sesion se guardara en un perfil aislado
   - Chrome se cierra cuando termine


================================================================================
USO NORMAL (UNA HU)
================================================================================

Para completar una certificacion de HU:

OPCION A - Playwright (RECOMENDADO):
1. Ejecutar: 6_Completar_HU_Playwright.bat

OPCION B - Selenium:
1. Ejecutar: 2_Completar_HU.bat

2. Ingresar el numero de HU cuando se solicite
   Ejemplo: 273920

3. El script automaticamente:
   - Buscara la carpeta "Evidencias HU273920" en Drive
   - Extraera los links de todas las carpetas CP
   - Actualizara el Excel de certificacion con los links

   -> Verifica cuantas quedaron completas despues del proceso

================================================================================
PROBLEMAS COMUNES
================================================================================

"Playwright no esta instalado":
-> Ejecuta: pip install playwright
-> Ejecuta: playwright install chromium

"ERR_INVALID_ARGUMENT" o "SessionNotCreatedException":
-> El perfil aislado ahora evita estos errores automaticamente
-> NO necesitas cerrar Chrome
-> Si persiste:
  1. Ejecuta: LIMPIAR_PERFIL_CHROME.bat
  2. Ejecuta: 7_Iniciar_Sesion_Playwright.bat (o 1_Iniciar_Sesion.bat)

"No se encontro la carpeta de HU en Drive"
-> Verificar que existe "Evidencias HU{numero}" en Drive (formato exacto)
-> Verificar que la sesion este guardada

"No se encontro certificacion para HU"
-> Verificar que existe Certificacion_QA_{numero}.xlsx
-> Verificar que esta en EntregaCerts/Certificaciones/AyN, RyC o Transversal

"Error al actualizar Excel"
-> Cerrar el archivo Excel si esta abierto
-> Verificar permisos de escritura

================================================================================
MODO AISLADO
================================================================================

El sistema usa un "perfil aislado" para Chrome (tanto Playwright como Selenium):

- Que es? -> Un Chrome completamente separado de tu Chrome personal
- Por que? -> Evita conflictos y errores como ERR_INVALID_ARGUMENT
- Ventajas? -> NO necesitas cerrar tu Chrome actual para usar el script
- Seguro? -> Tu sesion personal de Chrome NO es accedida por el script

Tu Chrome personal y el Chrome del script pueden estar abiertos al mismo tiempo
sin ningun problema.


================================================================================
POR QUE USAR PLAYWRIGHT?
================================================================================

Playwright es RECOMENDADO porque:
- Mejor manejo del scroll en Google Drive (carga lazy loading)
- Mas estable y menos errores de conexion
- Mejor deteccion de elementos dinamicos
- No requiere descargar ChromeDriver manualmente

Selenium sigue disponible como alternativa si hay problemas con Playwright.
